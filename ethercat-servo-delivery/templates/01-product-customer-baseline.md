## 3. 数值验收契约

下列符号在 checklist 中使用。**不得以“符合要求”“动作正常”代替冻结的数值或明确的状态序列。** 来源可以是客户需求、产品规格或经确认的工程基线，不能冒充 EtherCAT 统一阈值。

| 符号 | 应冻结的内容 | 当前值 |
| --- | --- | --- |
| T_boot / T_enable / T_mode / T_reset / T_recover | 上线、使能、切模式、复位、通信恢复最大时间；明确计时起止点 | 待确认 |
| C_set / J_max / D_max | 支持周期集合、主站任务抖动界限、设备同步误差界限；单位、统计窗口、测量方式 | 待确认 |
| T_watch / T_react / V_stop / S_stop | 看门狗设置、失联反应时间、停机速度判据和允许停机距离；按负载与停机策略区分 | 待确认 |
| T_stale / Hold_policy | 应用命令陈旧的判定时间、检测/处理责任方；若允许保持，冻结保持的物理量、最大持续时间和允许运动范围 | 待确认 |
| E_pos / E_follow / E_home / E_sync | 定位误差、跟随误差、回零重复误差、多轴同步误差；单位、负载与速度条件 | 待确认 |
| W_done / T_done / E_home_abs | 功能块到位监控开关、窗口及驻留时间；需要绝对原点精度时单独冻结E_home_abs，不能以重复性代替 | 待确认 |
| V_max / A_max / Jerk_max / Torque_max | 速度、加速度、加加速度、转矩限值及正负方向 | 待确认 |
| Override | 各动作允许的速度/加速度/加加速度倍率范围、生效时刻、置零与恢复规则 | 待确认 |
| P_jump / V_jump | 上电、使能、复位、模式切换时允许的位置/速度瞬态；观察窗口 | 待确认 |
| T_sdo / R_sdo / B_mailbox | SDO 超时、重试规则与允许后台通信负载 | 待确认 |
| N_repeat / H_soak / Duty | 循环次数、持续运行时长与运行负载 | 待确认 |
| T_first_motion / T_triage / T_restore | 新工程首次运动、支持定位和备件恢复的交付服务指标 | 待确认 |

首轮可讨论的工程起点：普通启动与恢复各 20 次、使能与基本运动各 100 次、持续运行 8 小时；这些仅用于规划工作量，不是正式合格阈值或寿命试验。故障注入次数应根据台架与风险单独确定，不能机械套用上述次数。

覆盖规则：

- 每个承诺支持的客户组合至少完成上线、运动、停止、异常恢复、保存和换机主路径。

- 平台软件、运动库、ESI、固件任一项变化，都做影响分析；不能将一个版本的通过结果直接复制给另一版本。
