# EtherCAT 伺服驱动器客户交付验收 checklist

版本 v0.1 / 2026-09-11。**本表是调研形成的验收设计，全部项目尚未执行。** 产品、固件、ESI、客户 PLC 和性能阈值尚未冻结，不代表已经兼容或验收通过。

## 使用和放行规则

1. 先填 [产品与客户基线](templates/01-product-customer-baseline.md)。每个实际交付组合单独复制结果列或建立 [单项记录](templates/02-test-record.md)，保留本表作为用例母版。
2. 所有条目是本项目的工程验收建议。**P0**：可能导致错误运动、无法建站、无法恢复或交付不可重现，应在受控客户试用前完成；**P1**：正式交付前完成；**P2**：扩展场景。P2 只表示安排优先级，凡已向客户承诺的功能仍必须验收。
3. 结果只用“未执行 / 通过 / 失败 / 阻塞 / N/A”。N/A 必须有不适用依据和对外能力边界。缺实机、缺判据、未实现但已承诺，均不能写 N/A 或通过。
4. 放行条件：适用项全部通过，或从交付范围中明确撤下未通过的功能/组合并更新资料；P0 失败、误动作、恢复策略未定义不可放行。通过率、平均成功率不能掩盖单次危险或未解释的失败。
5. 时间、精度、次数等符号来自基线。未冻结时标“阻塞”。每项必须有可复现操作、实测值和证据；UI 绿灯、“感觉正常”或一次能转不能代替结果。
6. 运动与故障注入先在具备限位、独立停止手段及负载约束的试验台执行。垂直负载、失转矩、制动器和电源中断按设备安全手册设计试验；本表不替代机器安全评估或安全功能认证。生产现场的在线下载/中断供电不作为默认测试方式。

证据缩写：**E0** 基线/版本/能力说明；**E1** 工程、ESI、PDO、Startup SDO和参数读回；**E2** PLC功能块＋驱动状态/目标反馈的同步Trace；**E3** 网络/AL/WKC/同步/SDO诊断及所需抓包；**E4** 机械测量/停机时间距离/输入与制动时序；**E5** 发布包/备份迁移/支持演练记录。证据需记录时间基准、采样周期和测量条件。
