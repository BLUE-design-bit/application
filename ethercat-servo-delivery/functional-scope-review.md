# EtherCAT 功能覆盖范围审定

状态：逐功能域审定中。此文件记录用户已拍板的范围，供后续统一重排 Excel；现有109项 Excel 尚未按新范围重排。

目标：开发、测试工程师亲手跑过参考品牌驱动器的 EtherCAT 功能，记录支持范围、实际表现和限制。条目按功能或行为组织，不编写操作教程。品牌保持 CDHD、台达、繁易、Elmo、KEBA（可选）。

## 1. 控制模式及模式切换：已确认

用户决定：删除 M08（IP及厂商扩展模式），其余9项保留。保留原编号以便追溯，不用其他条目填补 M08。

| 编号 | 功能 | 覆盖范围 |
| --- | --- | --- |
| M01 | CSP：周期同步位置 | 周期位置目标跟随、连续运动、位置偏置／前馈能力（如支持） |
| M02 | CSV：周期同步速度 | 正反向速度控制、零速、速度跟随、速度偏置（如支持） |
| M03 | CST：周期同步转矩 | 正反向转矩控制、转矩跟随、转矩偏置及速度限制（如支持） |
| M04 | PP：轮廓位置 | 绝对／相对定位、运动中接收新目标、目标确认与到位反馈 |
| M05 | PV：轮廓速度 | 正反转、加减速、目标速度更新、速度达到反馈 |
| M06 | PT：轮廓转矩 | 转矩目标更新、转矩斜坡、限幅及反馈 |
| M07 | HM：驱动器内部回零 | 支持的回零方法、完成／失败反馈、回零后的模式与位置状态 |
| M09 | 模式切换 | 哪些模式能够互切；未使能、已使能、运动中的切换限制；切换时的目标突变或异常动作 |
| M10 | 模式请求与反馈 | 请求模式与实际运行模式的一致性；不支持的模式或不允许的切换如何响应 |

结果含义：分别记录支持、不支持或受限及实际表现；品牌勾选表示已完成实测，不等于功能达标。仅资料确认不记为已实测。
