# EtherCAT 功能覆盖范围审定

状态：逐功能域审定中。此文件记录用户已拍板的范围，供后续统一重排 Excel；现有109项 Excel 尚未按新范围重排。

目标：开发、测试工程师亲手跑过参考品牌驱动器的 EtherCAT 功能，记录支持范围、实际表现和限制。条目按功能或行为组织，不编写操作教程。品牌保持 CDHD、台达、繁易、Elmo、KEBA（可选）。

| M04 | PP：轮廓位置 | 绝对／相对定位、运动中接收新目标、目标确认与到位反馈 |

## 全局要求：同时覆盖用户使用路径

用户新增要求：用户使用驱动器 EtherCAT 功能的路径都要遍历，明确包括导入 XML、ST、梯形图和调试界面。功能覆盖与入口覆盖同时成立；条目仍是需要验证的能力和行为，不改写成逐步操作教程。

后续 Excel 按“品牌 + 驱动/PLC版本组合 + 功能ID + 使用路径”保存独立记录。一个品牌功能格仅在全部适用路径和分支完成后汇总勾选，不能用某一个入口的成功代替其他入口。实际平台不具备的入口单独记录不适用及依据，缺软件/硬件或尚未测试不能记为不适用。

路径细分草案如下，具体清单后续单独交用户审定：

| 路径类型 | 应记录的覆盖分支 |
| --- | --- |
| XML / ESI 与工程配置 | 正式XML导入、版本更新；离线建站、在线扫描；正式设备描述与在线描述回退（如有） |
| ST 程序 | 客户实际使用的运动功能块、参数访问功能块及程序逻辑 |
| 梯形图程序 | 对应功能的梯形图调用及程序逻辑，单独留证，不沿用ST的结果 |
| PLC 调试界面 | 轴调试、点动/定位、参数在线读写、状态与报警查看等实际可用入口 |
| 控制方式 | 厂商运动库/原生轴控制与直接读写PDO、手写CiA402控制分别记录；与编程语言组合覆盖 |
| 参数下发方式 | 启动参数自动写入、程序主动SDO访问、在线对象浏览器读写及其并存/覆盖行为 |
| 厂家调试工具 | 明确实际经过EtherCAT、EoE或独立USB/串口/其他接口；独立接口成功不能代替EtherCAT路径 |
| 客户应用触发 | 适用的HMI操作、自动程序触发、多个入口并存与控制权交接 |

XML导入属于配置路径，ST/梯形图属于程序表达入口，PLC调试界面属于操作入口；它们不是同一维度的互斥选项。例如“导入ESI + ST + 运动库”与“导入ESI + 梯形图 + 运动库”应能分别追溯。用户要求覆盖全部适用路径，不在未经确认的情况下以抽样代替。

## 2. PDO / SDO 与对象访问：已确认

用户决定：D01—D09全部保留。D07按设备是否提供需要分段传输的大对象确定适用性；D06、D08、D09按下表澄清后的范围保留。参考品牌不支持某能力也要记录依据，不能与未测试混同。

| 编号 | 功能 | 覆盖范围 |
| --- | --- | --- |
| D01 | 默认及预设PDO | 提供的组合及各组合包含的控制、反馈和诊断数据 |
| D02 | 自定义PDO映射 | 映射对象调整、数量/长度/组合和可修改状态的限制 |
| D03 | PDO数据交换 | 数据类型、正负值、位宽、更新表现及无效数据/错误映射响应 |
| D04 | SDO读写 | 对象、权限、可写状态及生效时机 |
| D05 | SDO错误响应 | 不存在对象、只读对象、越界值和错误长度的响应 |
| D06 | 同一对象多个子项的整组访问（Complete Access） | 对实际支持对象验证整组读取/写入及限制；不能与任意多个对象的批量访问混同 |
| D07 | 大对象完整传输及分段SDO | 对实际存在的大对象验证完整传输；确认是否确实超过单次邮箱传输容量，不能把读短字符串等同验证分段 |
| D08 | 运动中读写参数 | 运动同时读诊断/参数、修改允许在线调整的参数，以及频繁访问对运动/通信的影响 |
| D09 | PDO / SDO 数据含义与一致性 | 对两条路径均可访问的对象，明确单位/缩放/权限/更新时机及生效差异；允许有文档依据的换算，不强制原始数字相等 |

### D06—D09 场景解释与资料依据

- D06：把同一对象下的多个子项作为一组访问。例如主站初始化时整组下发配置，而不是逐子项访问。它描述“访问哪些子项”，并不保证数据都在一个网络帧里完成。[Beckhoff CoE说明](https://infosys.beckhoff.com/content/1033/tc3_io_intro/1357984011.html)、[CODESYS启动参数的Full access](https://content.helpme-codesys.com/en/CODESYS%20EtherCAT/_ecat_edt_module_start_parameter.html)。
- D07：某个对象的数据超过邮箱可承载长度时，分多段传完。工程场景举例是设备确实提供的较长字符串、大数组或厂商数据块；它们是否存在、是否足够大须查实际对象字典。不能用FoE固件文件传输代替SDO分段。[ETG.1500 §5.7.2及5.7.3](https://www.ethercat.org/download/documents/ETG1500_V1i0i2_D_R_MasterClasses.pdf)，本次获取官方搜索索引中的相关段落，PDF直接抓取返回403。
- D08：工程场景举例是生产运动继续运行时，由PLC/HMI读取诊断数据，或用在线工具调整明确允许在线修改的参数。需分别了解可读/可写范围与访问负载下的行为，不能把“未使能时SDO读写成功”当作运行中也可用。[Beckhoff CoE Online](https://infosys.beckhoff.com/content/1033/tc3_io_intro/1446522251.html)提供在线对象读写和自动更新入口；运动中负载测试为本项目工程建议。
- D09：PLC使用PDO反馈，同时调试界面通过SDO查看同一对象时，需要知道数字的含义是否一致、是否需换算。Kollmorgen AKD官方资料确实列出某些配置下PDO与SDO位置缩放不同。该例只证明此类差异存在，不代表五个参考品牌均如此。动态量应考虑采样时刻，不能直接比两个不同时刻的数值。[Kollmorgen AKD位置缩放](https://www.kollmorgen.com/en-us/developer-network/position-scaling-akd-drive-ethercat-communication)。

以上资料于本轮答疑核查；应用举例与验收建议不构成对参考品牌已支持功能的声明。

## 3. 使能、停止与复位：已确认

用户决定：S01—S09全部保留。对实际平台支持的ST、梯形图、PLC调试界面和直接对象控制等入口分别留证；厂家工具记录其实际通信路径。

| 编号 | 功能 | 覆盖范围 |
| --- | --- | --- |
| S01 | 驱动状态与反馈 | 控制字命令与状态字反馈、允许的状态转换、无效命令/组合的响应 |
| S02 | 使能与撤使能 | 静止及运动中的使能/撤使能表现、重复使能、实际转矩与状态反馈 |
| S03 | 使能前置条件 | 主电源、硬件使能、STO等实际具备条件对EtherCAT使能的影响；条件未满足时的反馈及恢复行为 |
| S04 | PLC停止与暂停 | MC_Stop、MC_Halt或平台等效功能的减速、轴状态、后续命令接受条件与驱动实际表现 |
| S05 | 驱动快速停止（Quick Stop） | 可选停止方式、减速参数、停止后是否保持使能/转矩以及退出快速停止的条件 |
| S06 | 驱动暂停（Halt） | 各支持模式下的暂停、保持、恢复及目标处理；与PLC暂停入口分别留证 |
| S07 | 故障复位 | 故障仍存在/已经消除时的复位响应，驱动故障与PLC轴错误能否分别清除 |
| S08 | 停机或复位后恢复运动 | 是否需要重新使能、旧目标/旧命令的处理、位置连续性以及是否意外续跑 |
| S09 | 控制入口交接与冲突 | PLC程序、PLC调试界面、厂家工具等并存时的控制权、冲突响应与交接表现 |

S04记录PLC功能块这一层的能力，S05/S06记录驱动控制这一层的能力，实测时明确实际映射关系，不按名字合并为同一测试。S03关注安全/硬件条件与EtherCAT控制的联动，不以此代替独立安全功能验证。

## 4. 单位、坐标与位置反馈：待确认

以下10项为审定候选，不构成已批准范围。记录功能由驱动器还是PLC实现；各操作入口的换算、反馈与实际机械运动应能对照。功能不存在与测试尚未完成分别记录。

| 编号 | 候选功能 | 覆盖范围 |
| --- | --- | --- |
| U01 | 位置单位与电子齿轮 | 指令/反馈计数与实际转角或位移的换算、电子齿轮/传动比设置及其范围 |
| U02 | 速度单位 | 速度指令、反馈、限值的单位与换算，PLC显示和驱动反馈的对应关系 |
| U03 | 转矩单位 | 转矩指令、反馈、限值采用的基准与比例，例如相对额定转矩的比例或实际转矩单位 |
| U04 | 方向与极性 | 正反方向定义、方向反转设置对指令/反馈以及回零/限位方向的影响 |
| U05 | 坐标设定与零点偏置 | 驱动设零/偏置、PLC设位置等实际入口的支持范围，对反馈/目标/机械运动及重启保持的影响 |
| U06 | 绝对位置与掉电保持 | 实际支持的单圈/多圈位置、PLC或驱动重启后的机器坐标、断电移动后的反馈与位置有效性 |
| U07 | 增量位置与参考有效性 | 上电位置初值、回零/参考有效标志、重启或反馈异常后需要重新建立参考的条件 |
| U08 | 旋转轴与模数坐标 | 跨零/跨圈反馈、圈数、正反向与最短路径等实际可用定位方式；驱动与PLC各自的实现和限制 |
| U09 | 位置计数边界 | 实际位宽、正负边界、溢出/回绕；支持连续回绕时的表现，禁止跨界时的限制或错误响应 |
| U10 | 位置反馈来源 | 电机编码器、负载编码器、第二路反馈等实际存在的来源，EtherCAT可读取哪些值、能否选择及各自单位 |

同一参数既可在PLC设置又可在驱动设置时，记录两端各自作用及组合后的换算，避免将重复缩放或PLC实现能力误记为驱动能力。U08/U10按实际硬件与平台能力确定适用范围，不要求所有驱动具备多圈、模数规划或双编码器。
